# 0007 — Мультибренд: структура переменных и лимит Figma

**Status**: Accepted  
**Date**: 2026-05-26

## Context

При добавлении UI-предупреждения о лимите Figma (5000 переменных в коллекции) выяснилось, что формула для расчёта числа переменных в мультибренд-паке принципиально отличается от монобренда.

---

## Структура переменных в мультибренд-паке

`writeMultiBrandPack` создаёт два типа переменных:

### Semantic (системные, общие)
`[GroupName] Semantic/<Theme>/<Family>/<Suffix>`

Копируются из YC base colors один раз на весь пак, независимо от числа брендов.  
**Количество: 1092 переменных** (≈274 на тему × 4 темы, с небольшим отклонением по темам).

### Service/Brand (шкала бренда, per-brand)
`[GroupName] Service/<BrandName>/<Theme>/Brand/<Suffix>`

Создаются для каждого бренда отдельно: 30 значений на тему × 4 темы.  
**Количество: 120 переменных на бренд** (Solid: 20 индексов + Alpha: 10 индексов).

### Формула

```
total = 1092 + N × 120
```

| N брендов | Переменных |
|-----------|-----------|
| 1         | 1 212     |
| 8         | 2 052     |
| 10        | 2 292     |
| 32        | 4 932     |
| 33        | 5 052 ❌  |

**Монобренд (`writePrivateColorsFull`) ≠ мультибренд.** У монобренда те же 1212 переменных, но это семантические + шкала бренда вместе. В мультибренде семантика пишется один раз.

---

## Лимит Figma

Figma хардкодирует **5000 переменных на коллекцию**. При превышении `createVariable` бросает ошибку.

В обработчике `generate-multibrand` ошибка с "5000" в тексте перехватывается и переводится на русский:

```typescript
const message = /5000/i.test(raw)
  ? 'Превышен лимит Figma: в одной коллекции не может быть более 5000 переменных...'
  : raw;
```

---

## UI: предупреждение о лимите

`MultiBrandSection` получает `existingVarCount` (число переменных в локальной коллекции Private Colors, полученное из main thread при `ui-ready`).

Расчёт в UI (worst-case — как если семантика пишется заново):

```typescript
const plannedVars = VARS_SEMANTIC + entries.length * VARS_PER_BRAND_IN_PACK; // 1092 + N×120
const totalAfter  = existingVarCount + plannedVars;
const wouldExceed = totalAfter > 5000;
```

При `wouldExceed` показывается синий Alert вверху секции с раскладкой: `"Пак (1092 общих + N×120 = X перем.) не поместится."` Кнопка «Добавить бренд» блокируется раньше — при `addingOneMore`.

---

## Паттерн для будущего

- Никогда не использовать цифру 1212 для расчёта ёмкости мультибренд-пака — она справедлива только для монобренда.
- При добавлении нового пака с тем же `groupName` семантические переменные не создаются заново (`existing.get(varName) ?? createVariable`), поэтому реальная стоимость = `N × 120`. Но UI использует worst-case (с 1092), что правильно для нового group name.
- Максимум брендов в одном паке при пустой коллекции: **32** (1092 + 32×120 = 4932 < 5000).
