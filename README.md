# Gravity Brandifyer

Figma-плагин для добавления нового бренда в центральную дизайн-библиотеку **YC Gravity UI**.

Дизайнер вводит бренд-цвет — плагин генерирует полную шкалу приватных цветов, группу в коллекции Appearance и новую колонку в коллекции Brand. Всё пишется в ветку Figma и уходит на ревью стандартным образом.

---

## Как использовать (для дизайнера)

Рабочий процесс состоит из двух шагов, которые выполняются в разных файлах Figma.

### Шаг 1 — Файл приватных цветов

1. Создай новый пустой Figma-файл с названием `<BrandName> Private Colors`.
2. Открой плагин **Gravity Brandifyer** в этом файле.
3. Выбери режим и введи данные бренда (см. [Режимы генерации](#режимы-генерации) ниже).
4. Нажми **Сгенерировать** — плагин создаст коллекцию `Private Colors`.
5. Перейди на вкладку **Скачать CSS** — скачай или скопируй CSS-файл для фронтенда.
6. **Опубликуй файл как библиотеку** в Figma (`Assets → Publish`).

> **После публикации обновлённой библиотеки** плагин может видеть старый список брендов из-за кэша Figma API. Если бренды не появляются — полностью перезапусти Figma (не просто закрой файл), затем нажми ↻ рядом с полем «Бренд в библиотеке».

### Шаг 2 — Основная библиотека

1. Открой файл основной библиотеки Gravity UI.
2. Создай ветку (`Drafts → Create branch`).
3. **Подключи** только что опубликованную библиотеку приватных цветов к этой ветке (`Assets → Libraries`).
4. Открой плагин **Gravity Brandifyer** в ветке.
5. Введи название нового бренда, выбери нужную библиотеку приватных цветов в дропдауне.
6. Нажми **Сгенерировать** — плагин добавит группу в Appearance (~142 переменных) и новый модус в Brand (~215 переменных).
7. Перейди на вкладку **«Скачать CSS»** — там все бренды списком. Нажми **Скачать** или **Копировать** напротив нужного. Файл содержит оба слоя сразу: приватные цвета + branding-токены.
8. Отправь ветку на ревью через стандартный механизм Figma Branches.

## Режимы генерации

Плагин открывается в одном из двух состояний в зависимости от того, какие коллекции есть в текущем файле.

### Фаза 1 — Приватные цвета

Запускается в пустом файле (нет коллекций Appearance и Brand). Три подрежима:

| Режим | Когда использовать | Что создаёт |
|-------|--------------------|-------------|
| **Простой** | Один бренд, стандартные нейтральные цвета | ~1212 переменных: шкала Brand + все семейства из YC-базы |
| **Эксперт → Монобренд** | Один бренд, кастомные нейтральные (Blue, Green…) | То же, но с переопределёнными семействами |
| **Эксперт → Мультибренд** | Группа сервисных брендов в одном файле | Общие Semantic-цвета (1092) + Brand-шкала на каждый бренд (120 шт.) |

**Лимит Figma:** в одной коллекции `Private Colors` помещается не более 5000 переменных. Плагин показывает заполненность и блокирует генерацию, если новый пак не поместится (~32 бренда в пустой коллекции).

### Фаза 2 — Основная библиотека

Запускается в файле, где уже есть коллекции Appearance и Brand. Создаёт группу токенов для нового бренда и добавляет колонку в коллекцию Brand.

## Установка

### Просто использовать плагин

Папка `build/` закоммичена — собирать ничего не нужно.

1. `git clone <repo>`
2. В Figma: **Plugins → Development → Import plugin from manifest…**
3. Укажи `manifest.json` из папки репозитория.
4. Плагин появится в **Plugins → Development → Gravity Brandifyer**.

### Разработка

```bash
npm install
npm run dev   # живая пересборка при изменениях
```

Перед коммитом пересобери финальный билд:

```bash
npm run build
```
